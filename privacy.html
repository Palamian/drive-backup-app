Privacy Policy — Personal Drive Backup

Last updated: 2026-11-03

What this app is

A private, single-user OAuth client used by rclone on the owner's own computer to back up the owner's files to the owner's own Google Drive.

What data it accesses

Only the Google Drive files of the account that signs in, and only to read, write and list the backup files that the owner asks rclone to copy.

How the data is used

Google user data is used only to perform the backup the owner requests. Nothing is collected by the app's developer, nothing is sent to any server other than Google's, and no data is sold, shared or used for advertising.

Storage

The sign-in token is stored only in the rclone configuration file on the owner's own computer.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
